# Alexa Voice Assistant 🎤

A Python-based desktop voice assistant featuring a Tkinter Graphical User Interface (GUI), real-time speech recognition, and automated query responses.

## Features
- **Speech Recognition:** Listens to user voice commands using speech recognition.
- **Voice Response:** Provides spoken output powered by text-to-speech.
- **Automated Queries:** Answers time, date, day, and performs automated Wikipedia or web searches for general questions.
- **Standalone App:** Built as a standalone Windows executable so it runs without needing Python installed.
